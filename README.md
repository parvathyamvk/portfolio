## About

This repository contains my personal portfolio website. It introduces me as a Computer Science student and web developer, and brings together selected information about my education, skills, certifications, projects, and ways to contact me.

The website is built with HTML, CSS, and JavaScript, with a responsive layout and interactive elements.

- **Home:** Introduction, role, email address, social profile links, and quick navigation.
- **About Me:** Short introduction and development interests.

- **Education:** Academic background.
- **Certifications:** NPTEL Python, Cyber Security & Ethical Hacking workshop, and IEEE YESS'24 Summit.

## Run Locally

This is a static website, so no backend server or package installation is required for the basic portfolio.

### 1. Clone the repository

```bash
git clone https://github.com/parvathyamvk/portfolio.git
```

### 2. Open the project folder

```bash
cd portfolio
```

### 3. Run the website

Open `index.html` in your browser.

For a better development experience, you can open the folder in Visual Studio Code and use the **Live Server** extension.

## EmailJS Configuration

The contact form uses EmailJS. To make the form work with your own EmailJS account:

1. Create an account at [EmailJS](https://www.emailjs.com/).
2. Create an email service and an email template.
3. Update the EmailJS public key, service ID, and template ID in the relevant JavaScript initialization and `emailjs.send()` code.
4. Configure allowed origins/domain restrictions in your EmailJS account.
5. Test the form from your local website and deployed domain.

Do not put private email passwords, service-account credentials, or other server-side secrets in frontend code. The EmailJS public key is designed for client-side use, but should still be restricted using the provider's available settings.
